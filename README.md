# Loopfile

Free JetBrains IDE plugin for Tiltfiles. Works offline: no network calls, no data collection.

[![Downloads](https://img.shields.io/jetbrains/plugin/d/36122)](https://plugins.jetbrains.com/plugin/36122-loopfile)

## Install

In your IDE: **Settings | Plugins | Marketplace**, search for **Loopfile**, then **Install**. Or get it from [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/36122-loopfile).

## Features

- Highlighting for Tilt built-ins in `Tiltfile` files
- Structure view, completion and quick documentation
- Cmd+click on `load()` and `include()` paths
- A run configuration for your local `tilt` CLI
